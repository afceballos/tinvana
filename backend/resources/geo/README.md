# Colombia: DIVIPOLA

`colombia.json` deriva del conjunto **DIVIPOLA – Códigos municipios**, suministrado por el DANE en Datos Abiertos Colombia:
https://www.datos.gov.co/Mapas-Nacionales/DIVIPOLA-C-digos-municipios/gdxc-w37w

Licencia del conjunto: **Creative Commons Attribution-ShareAlike 4.0** (CC BY-SA 4.0), https://creativecommons.org/licenses/by-sa/4.0/ . Esta licencia se aplica al archivo de datos derivado, no al resto de la aplicación. Se conservan códigos oficiales y nombres, convertidos a formato de título y agrupados por departamento; se omiten coordenadas. La fecha de datos figura en el JSON. Consulta la fuente para actualizaciones; no se promete sincronización automática.

Incluye municipios, islas y áreas no municipalizadas tal como aparecen en la fuente. Su presencia no confirma cobertura de transporte ni disponibilidad de entrega. La lista no contiene códigos postales ni valida una dirección física.
